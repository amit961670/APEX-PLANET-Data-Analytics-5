# ApexPlanet Data Analytics Internship – Amit

## Project Overview
This repository contains the complete data analytics project completed as part of the **ApexPlanet Data Analytics Internship**.

The project uses the **Supermarket Sales Dataset** and follows an end-to-end analytics workflow: data cleaning, exploratory data analysis, SQL analysis, visualization, Power BI dashboarding, statistical analysis, customer segmentation, and machine learning.

## Tasks Completed

### Task 1 – Exploratory Data Analysis
- Data inspection and cleaning
- Missing-value and data-type checks
- Descriptive statistics
- Distribution and correlation analysis
- Sales and customer pattern exploration

### Task 2 – SQL Analysis
- SQLite database creation
- Data import and database utilities
- SQL filtering and aggregation
- GROUP BY, HAVING and JOIN-based analysis
- Business-oriented SQL queries

### Task 3 – Visualization & Power BI
- Python visualizations using Matplotlib, Seaborn and Plotly
- Sales trends and product analysis
- Branch/city performance analysis
- Customer and payment-method analysis
- Interactive Power BI dashboard with KPIs and filters

### Task 4 – Advanced Analytics
- Descriptive and correlation analysis
- Statistical/hypothesis testing
- Time-series analysis
- K-Means customer segmentation
- Predictive modelling

### Task 5 – Final Documentation
- Project organization
- Summary reports
- Final project documentation
- Supporting notebooks, scripts and visualizations

## Dataset
**Supermarket Sales Dataset**

The dataset contains transaction-level supermarket information including product lines, customer type, gender, quantity, pricing, sales, payment methods, ratings and branch/city information.

## Key Insights
- Sales and gross income have a positive relationship.
- Product lines contribute differently to total revenue and sales volume.
- Branch and city analysis helps compare business performance.
- Customer segmentation helps identify groups with different purchasing behaviour.
- Interactive dashboards make business insights easier to explore.
